# PANEL

沉浸式漫画阅读器，支持中英双语读本、逐句译校与按语言发布。

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 双语读本

- **以原句身份关联译文。** 每句对白有稳定 `line.id`，译文存放在
  `document.translations["en:<lineId>"]`，与显示顺序、页面顺序无关；重排分镜不会
  影响译文归属。
- **读者语言。** 阅读区顶部可切换中文 / English / 中英对照。切换语言只改变文案，
  镜头、缩放、阅读进度、书签仍指向同一分镜；朗读语音与每句阅读时长按所选语言估算。
  英语尚未发布时，语言按钮禁用，读者停留在中文。
- **未完成即回退。** 没有译文、译文为空或已「回退原文」的句子，读者看到原句并带有
  「显示原文」标记；原文被修改后，未复核的译句在译校台标记为待复核，读者
  端以「译文核对中」轻提示，仍可读到上一次译文。
- **逐句译校台。** 「逐句译校」按分镜列出原句与译文，可逐句保存草稿、审校通过、
  回退原文、查看审校历史与来源关系。所有操作只影响当前句与当前语言。

## 原文结构变化

| 变化 | 身份 | 译文处理 |
| --- | --- | --- |
| 原句修改 | 保留 `line.id` | 仅该句译文的 `sourceText` 快照不同 → 标记待复核，其他译文不动 |
| 拆分为多句 | 新句获得新 id，`lineage` 记录来源 | 旧译文作为第一句的草稿历史保留，不计为已审校 |
| 多句合并 | 新句获得新 id，`lineage` 记录全部来源 | 各旧译文进入新句历史，正文需重新翻译 |
| 整段替换 | 文本相同的句子保留 id；单句改写原位更新；结构变化生成新 id | 所有旧译文进历史，已审校内容不会静默消失 |

整段替换会先在副本上计算影响预览（原位修改 / 拆分 / 合并 / 改写数量，受影响译句与
已审校数量），确认后才写入。

## 多人协作

- 「导出我的译文 / 导出全部」生成 `panel-translations` JSON 包（含原句快照与审校
  状态）。
- 导入时：新句直接加入；与现有译文完全相同且导入方为已审校的草稿会升级为已审校；
  **内容不同则绝不覆盖**，而是作为冲突并列显示，由审校者选择「保留当前译文」或
  「采用此版本」。采用时旧版本进入历史。导入结果会汇总显示，重复行、失效原句会被
  跳过并提示。
- 发布：在「发布语言与翻译」中控制英文版是否对读者可见。下架不会删除译文或审校
  记录；正在阅读英文的读者会切回中文，位置保持不变。完整双语读本（含译文、历史、
  来源关系与发布设置）可整体导出 / 导入。

## 数据与兼容

会话保存在浏览器 `localStorage`（`panel-jdk014-v1`）。旧版单句对白（`panel.dialogue`）
在读取时自动迁移为一行对白 `lines`，页面与分镜 id 保持不变，因此书签与阅读位置继续
有效。旧会话默认只发布中文，需在译校后手动发布英文版。
